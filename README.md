### what's on the workbench

I'm not big on shipping fast — I usually make tools that I need and make them public for my friends to use too.

Two things I've been chipping away at lately:

- **[GodotAnimatedRichText](https://github.com/tioulon/GodotAnimatedRichText)** — text that doesn't just *appear*, it performs. Built this because vanilla `RichTextLabel` felt too stiff for dialogue that's supposed to have a personality.
- **[SproutyDialogsCap](https://github.com/tioulon/SproutyDialogsCap)** — my fork of a node-graph dialogue system for Godot. My version focuses on the backend and has some extra customization.
